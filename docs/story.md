# Neon District — 스토리

버티컬 슬라이스의 서사. 로드맵의 비트 시퀀스와 `DT_FixerDialogue`가 이 문서를 기준으로 한다.
톤은 한 줄로: **정산은 되지만 아무도 축하하지 않는다.**

## 전제

도시는 위로만 자란다. 아래층은 잊힌 지 오래고, 네온은 그 위에서만 켜진다.
플레이어는 **이름 없는 운반책**. 얼굴을 기억하는 사람이 없어서 일감이 들어온다. 오늘 밤 전화가 온다.

**Fixer** — 목소리만 있는 중개인. 한 번도 직접 만난 적 없고, 대로 끝 공중전화 부스가 접선 지점이다.
그가 사람을 '돌본다'고 말할 때 그건 다음 일감이 있다는 뜻이다.

**데이터칩** — 창고에 묻힌 것. 누구의 기억인지, 누구의 장부인지 모른다. 알려고 하면 값이 떨어진다.

## 비트 시퀀스

| 단계 | 게임 | 이야기 |
|---|---|---|
| 거리 | 스폰 → 대로 탐색 | 비 그친 직후. 간판이 웅덩이에 두 번 켜진다. 아무도 눈을 마주치지 않는다 |
| 통화 | Fixer E → `Intro_1~4` | 부스가 먼저 울린다. 번호는 없다 |
| 진입 | 트리거 → `Fighting` | 골목 끝 창고. 갱단이 먼저 와 있다 — 같은 물건을 찾고 있었다 |
| 전투 | 적 처치 | 총성은 이 구역에서 배경음이다. 아무도 신고하지 않는다 |
| 키 | `KeyDropped → KeyAcquired` | 마지막 하나가 쥐고 있던 키. 아직 따뜻하다 |
| 창고 | 문 → 칩 → `ItemAcquired` | 상자 하나, 칩 하나. 라벨은 지워져 있다 |
| 셔터 | 개방 | 뒤로 나가는 길이 열린다. 들어온 길로는 돌아가지 않는다 |
| 복귀 | Fixer E → `Return_1~3` | 부스. 값은 약속대로. 칩이 무엇이었는지는 끝내 묻지 않는다 |
| 엔딩 | `Completed` | 옥상. 도시. 랭크 |

| Row | 화자 | 본문 | Next | Effect |

행이 늘어난 것뿐이라 코드는 바뀌지 않는다. 시작 행 이름(`Intro_1`, `InProgress_1`, `Return_1`, `Completed_1`)은 NPC 프로퍼티 기본값 그대로.

## 엔딩

```text
Return_3 을 넘기는 순간
  → CompleteMission → OnStateChanged(Completed)
  → 화면 페이드 아웃 (1초)
  → 옥상 시퀀스: 실루엣의 뒷모습, 난간 앞. 도시는 보라·청색 네온으로 무한히 이어진다. 비 갠 하늘. 바람 소리만
  → 카메라가 아주 천천히 뒤로 빠진다 (8초)
  → 화면 하단, 작게, 오른쪽 정렬:
        RANK   S
        DEATHS 0
  → 그 위에 한 줄: "값은 들어왔다. 얼굴은 여전히 없다."
  → 5초 유지 후 페이드 아웃. 메뉴 없음, 버튼 없음. 그냥 끝
```

랭크가 크게 뜨지 않는 게 핵심이다. 성취가 아니라 **정산**처럼 — 작고, 조용하고, 아무도 축하하지 않는.
사망 횟수가 있으면 두 번째 줄에 그대로 찍혀서 "몇 번 죽고 여기 서 있나"가 된다.

## 구현 자리 (로드맵 7·8번)

- `Completed` 방송 → `ANeonDistrictPlayerController`가 구독 → 입력 잠금 → `ULevelSequencePlayer`로 옥상 시퀀스 재생.
  옥상은 플레이 구역 밖 별도 위치에 두고 시네마틱 카메라만 그쪽으로. 플레이어를 옮길 필요 없음 — 실루엣은 시퀀스 안의 마네킹.
- 랭크 위젯 `WBP_MissionResult`: 완료 시점에 `GetRank()` · `GetDeathCount()`를 한 번 읽어 채운다. 시퀀스 이벤트 트랙에서 표시 시점을 맞춘다.
- 실루엣 = 마네킹 + 역광 하나 + 언릿 검정 머티리얼. 배경 = Ring 2 원경 + Emissive 창문 인스턴스.
- 아트 주간(10/5~) 히어로 지점에 **옥상**을 추가한다 — 스크린샷이 나오는 지점.
